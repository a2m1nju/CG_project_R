# 길건너 친구들 네트워크 테스트

## Release x64 실행 및 접속

현재는 각자 자기 PC에서 서버를 실행하고 클라이언트를 `127.0.0.1`로 연결해 테스트한다. 다른 PC 간 접속은 아직 검증하지 않았다.

1. Visual Studio에서 [솔루션](컴그프젝%28찐%29.sln)을 열고 **Release | x64**를 선택해 빌드한다.
2. 시작 프로젝트를 **Server**로 설정해 실행하고 `Server listening on port 9000.`을 확인한다.
3. 클라이언트 프로젝트의 디버깅 설정에서 **명령 인수**에 서버 PC의 IPv4 주소를 입력한다. 같은 PC에서 테스트할 때는 `127.0.0.1`을 사용한다. 포트는 TCP `9000`으로 고정되어 있다. 작업 디렉터리는 셰이더와 글꼴이 있는 클라이언트 프로젝트 폴더 `$(ProjectDir)`를 사용한다.
4. 클라이언트의 `Connected to <서버 IP>:9000`과 서버의 `TCP session connected: <세션 ID>`를 확인한다. 명령 인수를 비워 두면 로컬 게임이 시작된다.
5. 서버 콘솔에서 Enter를 눌러 종료한다.

## y_merge 이동 통합

- `m_merge`의 기존 Server/ClientNetwork/Protocol 경로에 `yeonjin` 이동 기능을 통합했다. 별도 MovementTestServer, MoveClient, Shared/MoveProtocol.h는 사용하지 않는다.
- 연결한 상태에서 방향키를 누르면 기존 나무 충돌·역방향 아이템 검사를 거쳐 17바이트 MOVE를 전송한다. 서버가 30Hz 틱에서 방향·순번·라운드·생존·6틱(0.20초) 이동 간격을 검증하고 승인한 좌표로 기존 점프 애니메이션을 실행한다. 응답 대기 중에는 추가 이동을 보내지 않는다.
- 서버는 연결된 각 플레이어의 좌표를 **매 틱** 다음 형식으로 출력한다. 멈춰 있어도 출력된다.
  ```text
  [TICK 42] player=1 round=1 x=0 z=-1 alive=1
  ```
- 기존 인트로, 렌더링, 아이템, 차량·기차·물 충돌, 점수와 재시작 경로를 유지한다. 서버 주소를 생략하면 기존 로컬 게임으로 실행한다.
- 사망 후 기존 재시작 키를 누르면 이동 라운드와 좌표도 초기화된다. 이전 라운드의 입력/응답은 새 라운드에 적용하지 않는다.
- TCP 조각 수신/복수 프레임 수신/부분 송신을 처리하며 수신·송신 대기열은 각각 연결당 최대 16 KiB다. 잘못된 프레임이나 느린 수신자는 연결을 종료한다. 동시 TCP 연결 상한은 기존 8개다.
- 연결 종료 또는 이동 응답 5초 타임아웃은 연결을 정리한다. 재접속하려면 클라이언트를 다시 실행한다.

### 현재 구현 경계

`m_merge`의 맵·아이템·충돌 판정은 원래 클라이언트의 로컬 월드에서 동작한다. 이를 유지하기 위해 비이동 중 통나무·바나나에 의한 위치 변경과 사망 상태를 WorldPosition으로 서버에 동기화한다. **방향키 이동은 서버 승인을 받지만, 전체 월드가 서버 권위로 동기화된 멀티플레이는 아니다.** WorldPosition은 신뢰하는 클라이언트 데이터이며 부정행위 방지 수단이 아니다.

Room의 3인 매칭/JOIN·WELCOME/READY·LOADED/공유 월드/다른 플레이어 렌더링은 기존대로 후속 구현 대상이다. 현재 이동 라운드는 연결별 이동 상태이며 RoomController의 경기 시작을 대신하지 않는다. 다른 PC 간 연결은 검증하지 않았다.

### 검증

```text
python tests/movement_integration.py x64/Debug/Server.exe
```

실제 서버 프로세스와 TCP 연결을 사용해 조각 수신, 30Hz 상태/매틱 좌표 로그, 이동·쿨다운, 잘못된 입력/라운드, 환경 변위·사망, 리셋, 3개 연결, 잘못된 프레임, 재접속과 정상 종료를 검증한다. `tests/client_movement.cpp`는 실제 ClientNetwork의 승인 소비·입력 대기·리셋 경로를 검증하는 별도 콘솔 테스트다. 이를 빌드한 실행 파일 경로를 두 번째 인수로 전달하면 같은 서버에 연결해 검증한다. 그래픽 화면의 장시간 플레이는 자동 검증 범위에 포함하지 않았다.
