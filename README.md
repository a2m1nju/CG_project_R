# 길건너 친구들

OpenGL 기반 길건너기 게임 프로젝트입니다. 기존 게임에 서버 연결과 이동 요청 처리를 통합했습니다.

## 실행 방법

1. Visual Studio에서 `컴그프젝(찐).sln`을 엽니다.
2. **Release | x64**로 솔루션을 빌드합니다.
3. **Server** 프로젝트를 실행합니다.
4. 클라이언트 프로젝트의 **속성 → 디버깅**을 설정합니다.
   - **명령 인수:** `127.0.0.1`
   - **작업 디렉터리:** `$(ProjectDir)`
5. 서버를 켜 둔 상태에서 클라이언트를 실행합니다.

명령 인수를 비우면 서버에 연결하지 않고 로컬 게임으로 실행됩니다. 서버 콘솔에서 Enter를 누르면 서버가 종료됩니다.

## 주요 기능

- 기존 게임의 이동, 아이템, 장애물 충돌 및 점수 처리
- 서버의 이동 요청 검증과 승인 좌표 적용
- 초당 30틱의 서버 처리
- **1초마다 플레이어 위치 좌표 출력**
- 게임 재시작 시 이동 상태 초기화

```text
[TICK 30] player=1 round=1 x=0 z=-1 alive=1
[TICK 60] player=1 round=1 x=1 z=-1 alive=1
```

## 구현 범위

현재 맵·아이템·충돌 판정은 클라이언트에서 처리합니다. 공유 월드와 다른 플레이어 표시 등 전체 멀티플레이 기능은 아직 구현되지 않았습니다.
