# 길건너 친구들 네트워크 테스트

## Release x64 실행 및 접속

현재는 각자 자기 PC에서 서버를 실행하고 클라이언트를 `127.0.0.1`로 연결해 테스트한다. 다른 PC 간 접속은 아직 검증하지 않았다.

1. Visual Studio에서 [솔루션](컴그프젝%28찐%29.sln)을 열고 **Release | x64**를 선택해 빌드한다.
2. 시작 프로젝트를 **Server**로 설정해 실행하고 `Server listening on port 9000.`을 확인한다.
3. 클라이언트 프로젝트의 디버깅 설정에서 **명령 인수**에 서버 PC의 IPv4 주소를 입력한다. 같은 PC에서 테스트할 때는 `127.0.0.1`을 사용한다. 포트는 TCP `9000`으로 고정되어 있다. 작업 디렉터리는 셰이더와 글꼴이 있는 클라이언트 프로젝트 폴더 `$(ProjectDir)`를 사용한다.
4. 클라이언트의 `Connected to <서버 IP>:9000`과 서버의 `TCP session connected: <세션 ID>`를 확인한다. 명령 인수를 비워 두면 로컬 게임이 시작된다.
5. 서버 콘솔에서 Enter를 눌러 종료한다.

## 서버 연동 범위

- 현재 테스트 범위는 TCP 접속, 세션 ID 등록, 연결 종료 후 재접속이다. 서버는 끊긴 연결의 슬롯을 회수하고, 재접속에는 새 세션 ID를 부여한다.
- 동시 TCP 연결 상한은 8개다. 게임 참가 정원은 3명이다.
- 서버의 `JOIN`·`WELCOME` 처리는 준비 중이다. 현재 수신 데이터는 연결당 최대 16 KiB까지 쌓이고, 한도를 넘으면 해당 연결이 종료된다.
- `MOVE` 패킷 인코더는 구현되어 있다. 방향키 입력을 실제 송신으로 연결하는 작업과 서버의 이동 요청 처리는 준비 중이다.
- 서버가 종료되면 클라이언트 콘솔에 `Server disconnected.`가 표시되고 연결이 정리된다. 서버를 재시작한 뒤 접속을 시험할 때는 클라이언트도 다시 실행한다.
